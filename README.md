# Eten Teller 🍽️

Eenvoudige calorie- en eiwitteller voor je telefoon, met Nederlandse voedingswaarden (AH/NEVO-benadering).

**Open de app:** https://tarzan-moes.github.io/eten-teller/

## Op je Samsung installeren
1. Open de link hierboven in **Chrome**
2. Menu (⋮) → **Toevoegen aan beginscherm**
3. Klaar — werkt als app, data blijft offline op je toestel

## AI-herkenning (optioneel)
Standaard herkent de app ~34 veelgeete Nederlandse producten. Voor alles wat hij niet kent:
1. Maak een API-sleutel op https://ollama.com/settings/keys
2. Plak hem in ⚙️ Instellingen → druk op **🔑 Sleutel testen**
3. Verschenen er een 🤖-knop? Tik erop en AI rekent het uit (Ollama Cloud — geen model nodig op je telefoon)

Je sleutel en logboek blijven alleen op je toestel (localStorage).
